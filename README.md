# 20-10 💐

Thiệp mời chị em Mẹt Ú (dự án MedAvisor US) dự tiệc 20/10 – Ngày Phụ nữ Việt Nam tại Nhà hàng Ottugi.

## Xem qua GitHub Pages

1. Vào **Settings → Pages** của repo.
2. Ở **Build and deployment**, chọn **Source: Deploy from a branch**, branch `main`, thư mục `/ (root)` → **Save**.
3. Sau ~1 phút, thiệp sẽ có tại `https://son-dam.github.io/20-10/`.

## Chỉnh sửa

- Toàn bộ trang nằm trong `index.html` (không cần build).
- Giờ tổ chức chỉnh trong object `EVENT` ở đầu thẻ `<script>`.
